## 🛠️ Installation & Usage

### Prerequisites
*   Docker & Docker Compose
*   Node.js (for local CLI tools)
*   OpenAI API Key (in `.env`)

### Quick Start

1.  **Clone & Configure**:
    ```bash
    git clone https://github.com/Kolerr-Lab/Picked_OC_KFS4_COBOL-Knowledge-Graph-AI-Co-pilot_012926_1st.git
    cd Picked_OC_KFS4_COBOL-Knowledge-Graph-AI-Co-pilot_012926_1st
    cp .env.example .env
    # Add your OPENAI_API_KEY to .env
    ```

2.  **Launch the Core**:
    ```bash
    docker-compose up --build
    ```
    *This compiles the COBOL source, starts the Node.js Bridge, Postgres, and Redis.*

3.  **Run the Shock Demos**:
    In a separate terminal:
    ```bash
    # Run the "God's Eye" Topology Map
    node tests/topology_mapper.js

    # Run the HFT Flood Test
    node tests/hft_flood.js

    # View the Master Dashboard
    node tests/master_dashboard.js
    ```
